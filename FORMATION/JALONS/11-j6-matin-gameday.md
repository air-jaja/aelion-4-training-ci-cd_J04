# 11 — J6 matin — Game Day phases 0–2

> Windows, macOS ou Linux : suivre la section J6 du
> [guide multiplateforme](../GUIDE_MULTIPLATEFORME_APPRENANT.md).

Objectif : diagnostiquer une stack volontairement cassee sans regarder de
solution future.

Branche de travail dediee dans le depot de reference : `J6-gameday`. Ne pas
fusionner cette branche cassee dans son travail InduSense normal.

Recu par le jalon : briefing, roles, symptomes, registre de preuves et incidents
des phases 0–2. Aucun corrige, aucun post-mortem rempli.

A faire : etablir baseline, triager, formuler une hypothese testable, corriger
une panne a la fois et joindre une preuve avant/apres.

Preuve minimale : horodatage, symptome, commande, sortie utile, hypothese,
correctif reversible et test de non-regression.

Rattrapage : utiliser une nouvelle copie de la branche Game Day ; ne jamais
reinitialiser brutalement le depot personnel.
